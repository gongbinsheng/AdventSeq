# Figure 2B

File: `Figures/Figure2b.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 2B compares untargeted taxid totals across three methods for each host-mapper and viral-mapper combination: Kraken2, RVDB `read_count`, and RVDB `ViraQuant_scan` summarized at the `ncbitaxon` level. Each point represents one included sample under one method combination. Boxplots summarize the sample distributions.

Panels are arranged by:

- rows: `truth_group` (`Control` versus positive titration)
- columns: `virus_mapper` (`bowtie2` or `bwa_mem`)

The y-axis is untargeted taxids detected on a log10 scale.

## Immediate data source

The immediate source table is:

- `Analyses/tables/08_kraken2_rvdbv31_viraquant_scan_taxid_summary.tsv`

This table contains per-sample untargeted comparison summaries, including:

- `host_mapper`
- `virus_mapper`
- `truth_group`
- `kraken_taxids_total`
- `rvdb_taxids_total`
- `scan_taxids_total`
- `shared_all_three_taxids`

This figure uses the three-way comparison summary directly.

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads the three-way summary table from the updated `08` comparison output.
2. Converts `host_mapper` and `truth_group` to ordered factors for plotting.
3. Pivots `kraken_taxids_total`, `rvdb_taxids_total`, and `scan_taxids_total` into a long plotting table.
4. Uses `host_mapper` on the x-axis and taxid totals on the y-axis.
5. Colors and fills points/boxplots by untargeted method.
6. Facets by `truth_group` and `virus_mapper`.
7. Draws boxplots plus jittered sample-level points.
8. Applies a log10 y-axis scale.
9. Saves the plot as `Figures/Figure2b.pdf`.
