# Supplementary Table 1

File: `Tables/Suppl_Table1.tsv`

This table was generated by `make_manuscript_assets.R`.

## What the table shows

Supplementary Table 1 summarizes host-side mapping and quantification behavior by host mapper. It combines:

- median fraction of reads assigned to host
- median and mean numbers of detected genes
- median sample-wise mapper concordance values

## Immediate data sources

Supplementary Table 1 is assembled from:

- `Analyses/full_run/tables/02_normalization_denominators.tsv`
- `Analyses/full_run/tables/04_gene_detection_summary.tsv`
- `Analyses/full_run/tables/04_mapper_concordance.tsv`

The script filters:

- denominator rows to `include_analysis = TRUE`
- gene-detection rows to `include_analysis = TRUE` and `count_kind = "count_pairs"`
- mapper-concordance rows to `include_analysis = TRUE`

## How it was created

In `make_manuscript_assets.R`, the script:

1. Creates `assigned_summary` from `02_normalization_denominators.tsv` by computing:
   - `with_itself_and_mate_mapped / after_filtering_total_reads`
   - then taking the median by `host_mapper`
2. Summarizes `04_gene_detection_summary.tsv` by host mapper to get:
   - `median_genes_detected`
   - `mean_genes_detected`
3. Summarizes `04_mapper_concordance.tsv` by mapper pair to get median Spearman correlations.
4. Pivots the concordance summaries wide so each mapper-pair comparison becomes its own column.
5. Joins the host-assigned and gene-detection summaries with the concordance summary.
6. Saves the result as `Tables/Suppl_Table1.tsv`.

Relevant code block:

- `make_manuscript_assets.R`, around `assigned_summary`, `host_support_summary`, and `write_tsv_q(host_support_summary, "Suppl_Table1.tsv")`
