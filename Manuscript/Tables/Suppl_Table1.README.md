# Supplementary Table 1

File: `Tables/Suppl_Table1.tsv`

This table was generated by `make_manuscript_assets.R`.

## What the table shows

Supplementary Table 1 summarizes host-side mapping and quantification behavior by host mapper, with one row per host mapper:

- median fraction of reads assigned to host
- median and mean numbers of detected genes

Pairwise sample-wise mapper concordance (median Spearman correlation) is reported
separately in `Tables/Suppl_Table1_mapper_correlations.tsv`, because a pairwise
correlation is a property of a mapper PAIR, not of a single host mapper. The
previous version cross-joined those three correlation columns onto every
host-mapper row, which repeated the same value in each row and was misleading.

## Immediate data sources

Supplementary Table 1 is assembled from:

- `Analyses/full_run/tables/02_normalization_denominators.tsv`
- `Analyses/full_run/tables/04_gene_detection_summary.tsv`
- `Analyses/full_run/tables/04_mapper_concordance.tsv`

The script filters:

- denominator rows to `include_analysis = TRUE`
- gene-detection rows to `include_analysis = TRUE` and `count_kind = "count_pairs"`
- mapper-concordance rows to `include_analysis = TRUE` and `count_kind = "count_pairs"`
  (the `count_kind` filter was previously missing, so the reported correlations
  incorrectly pooled both `count_pairs` and `count_reads`; the corrected
  count-pairs-only medians are 0.986, 0.945, and 0.941)

## How it was created

In `make_manuscript_assets.R`, the script:

1. Creates `assigned_summary` from `02_normalization_denominators.tsv` by computing:
   - `with_itself_and_mate_mapped / after_filtering_total_reads`
   - then taking the median by `host_mapper`
2. Summarizes `04_gene_detection_summary.tsv` by host mapper to get:
   - `median_genes_detected`
   - `mean_genes_detected`
3. Joins the host-assigned and gene-detection summaries into one row per host mapper.
4. Saves the result as `Tables/Suppl_Table1.tsv`.
5. Separately summarizes `04_mapper_concordance.tsv` by mapper pair (one row per
   pair) and saves it as `Tables/Suppl_Table1_mapper_correlations.tsv`.
