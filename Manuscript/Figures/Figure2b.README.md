# Figure 2B

File: `Figures/Figure2b.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 2B compares, for each host-mapper and viral-mapper combination, how many taxids from a **shared RVDB background set** were detected by each of three methods: Kraken2, RVDB `read_count`, and RVDB `ViraQuant_scan` (summarized at the `ncbitaxon` level). This is the **fair** comparison: all three methods are scored against the same background taxid universe (RVDB-backed taxids at ranks S/S1/S2) rather than against their own unbounded outputs. Each point represents one included sample under one method combination; boxplots summarize the sample distributions.

Panels are arranged by:

- rows: `truth_group` (`Control` versus positive titration)
- columns: `virus_mapper` (`bowtie2` or `bwa_mem`)

The y-axis is untargeted taxids detected on a log10 scale.

## Immediate data source

The immediate source table is:

- `Analyses/tables/08_kraken2_rvdbv31_taxid_summary_fair_background.tsv` (or the `Analyses/full_run/tables/` copy), filtered to `background_rank == "ALL_SELECTED"`

This table contains per-sample untargeted comparison summaries, including:

- `host_mapper`
- `virus_mapper`
- `truth_group`
- `background_taxids_total`
- `kraken_taxids_total`
- `rvdb_taxids_total`
- `scan_taxids_total`

This table is produced by `Scripts/08_compare_kraken2_rvdb_taxid_fair.R`. The figure uses the fair-background summary directly (one row per sample / host_mapper / virus_mapper after keeping `background_rank == "ALL_SELECTED"`).

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads the fair-background summary table and keeps `background_rank == "ALL_SELECTED"`.
2. Converts `host_mapper` and `truth_group` to ordered factors for plotting.
3. Pivots `kraken_taxids_total`, `rvdb_taxids_total`, and `scan_taxids_total` into a long plotting table.
4. Uses `host_mapper` on the x-axis and taxid totals on the y-axis.
5. Colors and fills points/boxplots by untargeted method.
6. Facets by `truth_group` and `virus_mapper`.
7. Draws boxplots plus jittered sample-level points.
8. Applies a log10 y-axis scale.
9. Saves the plot as `Figures/Figure2b.pdf`.

- `make_manuscript_assets.R`, around the `plot_untarget` object and `save_plot(plot_untarget, "Figure2b.pdf", ...)`
