# General virus panel

A small panel of seven viral RefSeq genomes that are common adventitious agents
of biological products and cell substrates. It is used for targeted
quantification (ViraQuant with a virus list) and variant calling (GATK4
Mutect2). Replace it with the viruses relevant to your own study.

| Accession | Virus | Name in results |
| --- | --- | --- |
| NC_001792.2 | Porcine circovirus 1 | PCV1 |
| NC_005148.1 | Porcine circovirus 2 | PCV2 |
| NC_001510.1 | Minute virus of mice | MVM |
| NC_001461.1 | Bovine viral diarrhea virus 1 | BVDV-1 |
| NC_001669.1 | Simian virus 40 | SV40 |
| AC_000008.1 | Human adenovirus 5 | HAdV-5 |
| NC_001501.1 | Moloney murine leukemia virus | MoMLV |

Included in the repository (small text files):

```
accessions.txt       # the NCBI RefSeq accessions
virus_list.txt       # ViraQuant --viruses: <contig id> <virus name>
contig_info.json     # TaxonomyClassifier --contig_info: per-contig metadata
```

Generated by the preparation steps in the main
[README.md](../../../README.md#step-2-reference-data):

```
viruses.fa, viruses.fa.fai, viruses.dict   # genome FASTA + samtools/GATK indexes
BWAIndex/viruses.fa.*                      # BWA index (.amb .ann .bwt .pac .sa)
```

To use other viruses, list their accessions in `accessions.txt`, then update
`virus_list.txt` (one `<accession> <name>` line per genome; names must not
contain spaces, and several accessions may share one name) and
`contig_info.json` (one entry per accession with at least `organism`).
