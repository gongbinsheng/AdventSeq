# Supplementary Figure 1

File: `Figures/Suppl_Figure1.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Supplementary Figure 1 shows host-expression PCA results for the included samples using count-pair host gene quantification. Points are colored by `experiment_protocol` and shaped by `library_type`. Panels are faceted by `host_mapper`.

The figure is intended to show that the overall host-expression sample structure is preserved across host mappers.

## Immediate data source

The immediate source table is:

- `Analyses/full_run/tables/04_host_pca_scores.tsv`

The script filters this table to:

- `include_analysis = TRUE`
- `count_kind = "count_pairs"`

Relevant columns used for plotting include:

- `PC1`
- `PC2`
- `host_mapper`
- `experiment_protocol`
- `library_type`

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads `04_host_pca_scores.tsv`.
2. Keeps included `count_pairs` rows.
3. Converts `host_mapper` and `library_type` to ordered factors.
4. Plots `PC1` versus `PC2`.
5. Colors points by `experiment_protocol` and shapes them by `library_type`.
6. Facets by `host_mapper`.
7. Saves the plot as `Figures/Suppl_Figure1.pdf`.

Relevant code block:

- `make_manuscript_assets.R`, around the `plot_pca` object and `save_plot(plot_pca, "Suppl_Figure1.pdf", ...)`
