# Figure 4A

File: `Figures/Figure4a.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 4A shows a sample-level comparison for representative sample `1_S1`, contrasting HEV and Zika by mapped-read totals across host-mapper / virus-mapper combinations.

The bars show `abundance_raw_read_count + 1` for the two viruses. The purpose is to illustrate that mapped-read totals alone can suggest stronger HEV support than Zika under some permissive subtraction settings.

## Immediate data sources

Figure 4A is based on an intermediate table called `coverage_case`, which is built from:

- `Analyses/full_run/tables/07_read_count_viraquant_matched.tsv`
- `Analyses/full_run/tables/06_viraquant_records.tsv`

`07_read_count_viraquant_matched.tsv` provides matched read-count and ViraQuant-linked sample/virus rows.

`06_viraquant_records.tsv` provides virus-level coverage fields, from which the script uses:

- `frac_ge_1`
- `mean_depth_ge_1`
- `pass_k_90pct_ge_1`

## How it was created

In `make_manuscript_assets.R`, the script:

1. Joins `07_read_count_viraquant_matched.tsv` with virus-level rows from `06_viraquant_records.tsv`.
2. Filters to sample `1_S1`.
3. Filters to viruses `HEV` and `Zika`.
4. Creates a `method` label from `host_mapper / virus_mapper`.
5. Defines `abundance_plot = abundance_raw_read_count + 1` for log-scale plotting.
6. Draws grouped bars by method and virus.
7. Saves the plot as `Figures/Figure4a.pdf`.

The same `coverage_case` intermediate table is also written out as `Tables/Table3.tsv`.
