# Placeholder: your FASTQ files

No FASTQ files are provided with AdventSeq. Put your own paired-end RNA-seq
FASTQ files here and list them, one sample per row, in the `SRA_data` sheet of
`../../SRA_metadata_example.xlsx` (columns `library_ID`, `filename1`,
`filename2`, ...). Each file name must start with the sample's `library_ID`
and contain the read number, e.g. `<library_ID>_R1_001.fastq.gz`.

See "Step 1: FASTQ data" in the main
[README.md](../../../README.md#step-1-fastq-data).
