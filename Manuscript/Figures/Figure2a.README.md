# Figure 2A

File: `Figures/Figure2a.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 2A shows the number of QC-passing reads that remained after host subtraction for each host mapper (`bwa_mem`, `HISAT2`, and `STAR`). Each point represents one included sample under one host-mapper setting. Boxplots summarize the distribution within each protocol, and panels are faceted by `experiment_protocol`.

The y-axis is `denom_non_host_reads` on a log10 scale.

## Immediate data source

The immediate source table is:

- `Analyses/full_run/tables/02_normalization_denominators.tsv`

This table contains, for each sample and host mapper:

- `after_filtering_total_reads`
- `with_itself_and_mate_mapped`
- `denom_non_host_reads`
- sample metadata columns such as `experiment_protocol` and `truth_group`

In this summary table, `denom_non_host_reads` represents the number of QC-passing reads not assigned to host after host subtraction.

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads `02_normalization_denominators.tsv` and keeps rows with `include_analysis = TRUE`.
2. Uses `denom_non_host_reads` as the plotted response.
3. Uses `host_mapper` on the x-axis.
4. Facets by `experiment_protocol`.
5. Draws boxplots plus jittered sample-level points.
6. Applies a log10 y-axis scale.
7. Saves the plot as `Figures/Figure2a.pdf`.

Relevant code block:

- `make_manuscript_assets.R`, around the `plot_nonhost` object and `save_plot(plot_nonhost, "Figure2a.pdf", ...)`
