It combines raw mapped-read summaries with coverage-aware ViraQuant fields so the same rows can support both Figure 4A and Figure 4B.

## How it was created

1. Starts from `07_read_count_viraquant_matched.tsv`.
2. Joins virus-level fields from `06_viraquant_records.tsv`.

4. Creates an ordered method label from `host_mapper / virus_mapper`.
5. Selects the final columns used for reporting.
6. Saves the result as `Tables/Suppl_Table3.tsv`.
