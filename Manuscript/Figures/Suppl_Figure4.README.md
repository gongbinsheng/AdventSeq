# Supplementary Figure 4

File: `Figures/Suppl_Figure4.pdf`

This figure was generated by `make_manuscript_assets.R` and replaces the former
Supplementary Table 3 (the manuscript now contains no supplementary tables).

## What the figure shows

Per-protocol medians of `fastp` QC trimming behavior, as three stacked panels
sharing a common protocol x-axis (ordered by median adapter-trimmed fraction):

- **A.** Median adapter-trimmed and polyX-trimmed read fractions (% of total raw reads)
- **B.** Median Q20 and Q30 quality-rate gains after QC (percentage points)
- **C.** Median composition of polyX-trimmed reads (polyA / polyT / polyC / polyG, %)

Each row corresponds to one `experiment_protocol`.

## Immediate data source

- `Tables/Suppl_Figure4_data.tsv` (the per-protocol summary, also written by the script)

This is assembled from per-sample `fastp` JSON files in `Results/fastp` joined to
`Analyses/full_run/tables/01_sample_metadata.tsv`, exactly as the former
Supplementary Table 3.

## How it was created

In `make_manuscript_assets.R`, the script:

1. Builds the per-protocol summary object `fastp_protocol_summary`.
2. Writes it to `Tables/Suppl_Figure4_data.tsv`.
3. Pivots the summary into a long panel/series table (`sf4_long`).
4. Draws dodged bars faceted by panel (`facet_wrap(~panel, ncol = 1, scales = "free_y")`).
5. Saves the plot as `Figures/Suppl_Figure4.pdf` via `save_plot()`.

Relevant code block:

- `make_manuscript_assets.R`, around `plot_fastp_qc` and `save_plot(plot_fastp_qc, "Suppl_Figure4.pdf", ...)`
