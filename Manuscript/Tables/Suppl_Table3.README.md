# Supplementary Table 3

File: `Tables/Suppl_Table3.tsv`

This table was generated by `make_manuscript_assets.R`.

## What the table shows

Supplementary Table 3 summarizes protocol-level QC trimming behavior from `fastp`, focusing on:

- median fraction of adapter-trimmed reads
- median fraction of polyX-trimmed reads
- median Q20 and Q30 gains
- median composition of polyX-trimmed reads by nucleotide

Each row corresponds to one `experiment_protocol`.

## Immediate data sources

Supplementary Table 3 is assembled from:

- per-sample `fastp` JSON files in `Results/fastp`
- `Analyses/full_run/tables/01_sample_metadata.tsv`

The JSON files provide:

- `adapter_trimmed_reads`
- `total_polyx_trimmed_reads`
- polyA/polyT/polyC/polyG counts
- before/after Q20 and Q30 rates

The sample metadata table provides:

- `sample_id`
- `experiment_protocol`
- `include_analysis`

## How it was created

In `make_manuscript_assets.R`, the script:

1. Lists all `.fastp.json` files in `Results/fastp`.
2. Parses each JSON file with `parse_fastp_json()`.
3. Joins the parsed per-sample QC values to included sample metadata from `01_sample_metadata.tsv`.
4. Computes per-sample derived fields:
   - `adapter_trimmed_fraction`
   - `polyx_trimmed_fraction`
   - `q20_gain`
   - `q30_gain`
   - `polyA_fraction`, `polyT_fraction`, `polyC_fraction`, `polyG_fraction`
5. Groups by `experiment_protocol` and takes medians of those values.
6. Converts them to percentages.
7. Sorts rows by `median_adapter_trimmed_reads_pct`.
8. Saves the result as `Tables/Suppl_Table3.tsv`.
