## What the figure shows

Figure 3 compares targeted panel viral burden across host subtraction methods and viral mappers. It shows the normalized targeted abundance for control versus positive-titration libraries.

Each point represents one included sample under one host-mapper / virus-mapper combination. Boxplots summarize the sample distributions. Panels are faceted by `virus_mapper`.

The plotted response is `norm_total_reads + 0.01` on a log10 scale.

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads `05_targeted_read_count_summary.tsv`.
2. Converts `host_mapper` and `truth_group` to ordered factors.
3. Defines `norm_total_plot = norm_total_reads + 0.01` so zero-valued observations can be shown on a log scale.
4. Uses `host_mapper` on the x-axis and `norm_total_plot` on the y-axis.
5. Colors and fills points/boxplots by `truth_group`.
6. Facets by `virus_mapper`.
7. Saves the plot as `Figures/Figure3.pdf`.
