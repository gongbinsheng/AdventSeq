## What the table shows

Supplementary Table 2 reports virus-level concordance between read-count summaries and ViraQuant summaries for each host-mapper / virus-mapper combination.

The table includes:

- selected abundance field
- Spearman correlation using total-read normalization
- Spearman correlation using non-host-read normalization
- Spearman correlation using raw values
- number of matched virus-level rows
