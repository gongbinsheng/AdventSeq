# Figure 4B

File: `Figures/Figure4b.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 4B uses the same representative sample `1_S1` and the same HEV-versus-Zika comparison as Figure 4A, but plots coverage breadth instead of raw mapped-read totals.

The bars show `frac_ge_1 * 100`, which is the percentage of genome positions with depth greater than or equal to 1. Text labels indicate whether each virus passed the `pass_k_90pct_ge_1` threshold.

## Immediate data sources

Figure 4B uses the same `coverage_case` intermediate table as Figure 4A, built from:

- `Analyses/full_run/tables/07_read_count_viraquant_matched.tsv`
- `Analyses/full_run/tables/06_viraquant_records.tsv`

The relevant fields are:

- `frac_ge_1`
- `pass_k_90pct_ge_1`
- sample and method identifiers

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reuses the filtered `coverage_case` data for sample `1_S1` and viruses `HEV` and `Zika`.
2. Creates a `method` label from `host_mapper / virus_mapper`.
3. Plots `frac_ge_1 * 100` as grouped bars.
4. Adds text labels showing `90% pass` or `90% fail` from `pass_k_90pct_ge_1`.
5. Saves the plot as `Figures/Figure4b.pdf`.

Relevant code blocks:

- `make_manuscript_assets.R`, around `coverage_case`
- `make_manuscript_assets.R`, around `coverage_plot_data` and `plot_case_breadth`
