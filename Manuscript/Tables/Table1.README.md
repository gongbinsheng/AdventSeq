# Table 1

File: `Tables/Table1.tsv`

This table was generated by `make_manuscript_assets.R`.

## What the table shows

Table 1 is a protocol-level summary of the study dataset used to showcase AdVentSeq. It combines:

- sample counts by protocol
- inoculum-group counts by protocol
- median post-filtering read depth
- median retained fraction after QC
- median non-host read counts after host subtraction for each host mapper

Each row corresponds to one `experiment_protocol`.

## Immediate data sources

Table 1 is assembled from three summary tables:

- `Analyses/full_run/tables/01_sample_metadata.tsv`
- `Analyses/full_run/tables/02_fastp_sample_summary.tsv`
- `Analyses/full_run/tables/02_normalization_denominators.tsv`

These contribute the following information:

- `01_sample_metadata.tsv`: protocol identity, library type, replicate labels, and `include_analysis`
- `02_fastp_sample_summary.tsv`: `after_filtering_total_reads` and `after_vs_before_fraction`
- `02_normalization_denominators.tsv`: `denom_non_host_reads` for each host mapper

## How it was created

In `make_manuscript_assets.R`, the script:

1. Starts from `01_sample_metadata.tsv` and counts included samples within each `experiment_protocol`.
2. Counts how many included samples are `Control`, `1:1`, and `10:1`.
3. Joins protocol-level medians from `02_fastp_sample_summary.tsv`:
   - `median_after_filtering_reads`
   - `median_retained_fraction`
4. Joins protocol-level medians of `denom_non_host_reads` from `02_normalization_denominators.tsv`, grouped by both `experiment_protocol` and `host_mapper`.
5. Pivots the host-mapper medians wide so each protocol has separate columns for:
   - `median_non_host_reads_HISAT2`
   - `median_non_host_reads_STAR`
   - `median_non_host_reads_bwa_mem`
6. Sorts rows by `median_after_filtering_reads`.
7. Saves the result as `Tables/Table1.tsv`.
