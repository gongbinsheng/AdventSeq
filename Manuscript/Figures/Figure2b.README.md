# Figure 2B

File: `Figures/Figure2b.pdf`

This figure was generated by `make_manuscript_assets.R`.

## What the figure shows

Figure 2B shows the number of taxa detected in untargeted RVDB screening for each host-mapper and viral-mapper combination. Each point represents one included sample under one method combination. Boxplots summarize the sample distributions.

Panels are arranged by:

- rows: `truth_group` (`Control` versus positive titration)
- columns: `virus_mapper` (`bowtie2` or `bwa_mem`)

The y-axis is `taxa_detected` on a log10 scale.

## Immediate data source

The immediate source table is:

- `Analyses/full_run/tables/05_untargeted_read_count_summary.tsv`

This table contains untargeted RVDB summary values for each sample, including:

- `host_mapper`
- `virus_mapper`
- `truth_group`
- `norm_total_reads`
- `norm_non_host_reads`
- `taxa_detected`

This figure uses the RVDB untargeted summary directly. It does not use Kraken2 counts.

## How it was created

In `make_manuscript_assets.R`, the script:

1. Reads `05_untargeted_read_count_summary.tsv`.
2. Converts `host_mapper` and `truth_group` to ordered factors for plotting.
3. Uses `taxa_detected` as the plotted response.
4. Uses `host_mapper` on the x-axis.
5. Facets by `truth_group` and `virus_mapper`.
6. Draws boxplots plus jittered sample-level points.
7. Applies a log10 y-axis scale.
8. Saves the plot as `Figures/Figure2b.pdf`.

Relevant code block:

- `make_manuscript_assets.R`, around the `plot_untarget` object and `save_plot(plot_untarget, "Figure2b.pdf", ...)`
