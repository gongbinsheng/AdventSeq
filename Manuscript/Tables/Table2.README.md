# Table 2

File: `Tables/Table2.tsv`

This table was generated by `make_manuscript_assets.R`.

## What the table shows

Table 2 is a method-level comparison table with one row per host-mapper and viral-mapper combination. It brings together targeted-alignment summaries, untargeted-alignment summaries, ViraQuant summaries, the three-way untargeted taxid comparison across Kraken2, RVDB `read_count`, and RVDB `ViraQuant_scan`, and host-assigned fractions.

The table is meant to support cross-method comparison rather than list per-sample values.

## Immediate data sources

Table 2 is assembled from five summary tables:

- `Analyses/full_run/tables/02_normalization_denominators.tsv`
- `Analyses/full_run/tables/05_targeted_read_count_summary.tsv`
- `Analyses/full_run/tables/05_untargeted_read_count_summary.tsv`
- `Analyses/full_run/tables/06_viraquant_sample_summary.tsv`
- `Analyses/tables/08_kraken2_rvdbv31_taxid_summary_fair_background.tsv (background_rank == "ALL_SELECTED")`

These contribute the following information:

- targeted panel burden and viruses detected
- untargeted RVDB burden and taxa detected
- ViraQuant primary abundance and pass-count summaries
- Kraken2, RVDB `read_count`, and `ViraQuant_scan` taxid totals plus their shared and Kraken-only components
- fraction of reads assigned to host

## How it was created

In `make_manuscript_assets.R`, the script first builds several intermediate summaries:

1. `assigned_summary`
   - Source: `02_normalization_denominators.tsv`
   - Computes `assigned_fraction = with_itself_and_mate_mapped / after_filtering_total_reads`
   - Takes the median by `host_mapper`

2. `target_summary`
   - Source: `05_targeted_read_count_summary.tsv`
   - Groups by `host_mapper`, `virus_mapper`, and `truth_group`
   - Takes medians of:
     - `norm_total_reads`
     - `viruses_detected`
   - Pivots control and positive-titration values into separate columns

3. `untarget_summary`
   - Source: `05_untargeted_read_count_summary.tsv`
   - Groups by `host_mapper`, `virus_mapper`, and `truth_group`
   - Takes medians of:
     - `norm_total_reads`
     - `taxa_detected`
   - Pivots control and positive-titration values into separate columns

4. `vq_summary`
   - Source: `06_viraquant_sample_summary.tsv`
   - Groups by `host_mapper`, `virus_mapper`, and `truth_group`
   - Takes medians of:
     - `primary_normalized_abundance`
     - `n_pass_k_90pct_ge_1`
   - Pivots control and positive-titration values into separate columns

5. `kraken_summary`
   - Source: `08_kraken2_rvdbv31_taxid_summary_fair_background.tsv (background_rank == "ALL_SELECTED")`
   - Groups by `host_mapper` and `virus_mapper`
   - Takes medians of:
     - `kraken_taxids_total`
     - `rvdb_taxids_total`
     - `scan_taxids_total`
     - `shared_all_three_taxids`
     - `kraken_only_taxids`
     - `shared_all_three_rvdb_fraction`

The script then left-joins all of these summaries into one combined method table and saves it as `Tables/Table2.tsv`.
